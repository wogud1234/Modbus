# cs/일반

> 작성일: 2026-10-05

## 요약

C#의 `int?` (Nullable 타입)은 값이 없을 수도 있는 변수를 표현한다. Java의 `Optional<>`과 유사한 개념이며, JSON 역직렬화 시 필드 누락과 0을 구분할 수 있다.

## 주요 내용

### `int?` — Nullable 타입

`int?`는 `Nullable<int>`의 줄임 표현이다.

```csharp
int  CoilCount   // null 불가 — 반드시 값 있어야 함
int? CoilCount   // null 가능 — 값이 없을 수도 있음
```

### Java Optional과 비교

| | C# `int?` | Java `Optional<Integer>` |
|---|---|---|
| null 체크 | `x.HasValue` | `x.isPresent()` |
| 값 꺼내기 | `x.Value` | `x.get()` |
| null이면 기본값 | `x ?? 0` | `x.orElse(0)` |
| null 대입 | `x = null` | `x = Optional.empty()` |

### 왜 Nullable을 쓰나

JSON 파일에서 해당 필드가 없을 수도 있기 때문이다.

```json
// coilCount 필드가 없는 JSON
{ "holdingCount": 62 }
```

- `int`면 역직렬화 시 강제로 `0`이 들어감
- `int?`면 `null`이 들어와서 **"설정 안 됨"과 "0으로 설정됨"을 구분** 가능

## 용어 정리

| 용어 | 설명 |
|---|---|
| `int?` | `Nullable<int>`의 줄임. null을 허용하는 int |
| `HasValue` | Nullable 타입에 값이 있는지 확인하는 속성 |
| `Value` | Nullable 타입에서 실제 값을 꺼내는 속성 |
| `??` | null 병합 연산자. 왼쪽이 null이면 오른쪽 값 사용 |
| 역직렬화 (Deserialization) | JSON 문자열을 C# 객체로 변환하는 과정 |
