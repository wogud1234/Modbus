# [Server/Modules에 구현해 놓은거 테스트할거야. KepserverEx로 테스트할 거임.]
# 아래 내용들을 구현해.

[1] FormIndex.cs 에서 비전, 제어, MES 버튼을 클릭하면,
    각각 VisionMain, ControlMain.cs, MesHostMain.cs 폼들이 열려. 
    
[2] VisionMain.cs 폼 열린 후
    이 폼에서는 비전 mmf를 열고 dgvMmf에 데이터를 나타낼거야.
    자동 버튼을 누르면 임의의 값들로 주기적으로 데이터를 mmf에 쓰고,
    수동 버튼을 누르면 주기적으로 데이터 쓰는 것을 멈추고 수동으로 내가 컬럼의 값을 수정할 거야
    
[3] ControlMain.cs 폼 열린 후
    이 폼에서는 제어 mmf를 열고 dgvMmf에 데이터를 나타낼거야.
    자동 버튼을 누르면 임의의 값들로 주기적으로 데이터를 mmf에 쓰고,
    수동 버튼을 누르면 주기적으로 데이터 쓰는 것을 멈추고 수동으로 내가 컬럼의 값을 수정할 거야
    
[4] MesHostMain.cs 폼 열린 후
    이 폼에서는 vision/control 의 mmf를 주기적으로 읽어서 Store에 저장하고,
    dgvStore에 그 데이터들을 나타낼거야.
    그리고 KepserverEx가 데이터 요청을 하면 ModbusTcpSlave가 요청을 받아서 응답할거야.
    
[5] 이 밖에도 테스트 하기에 필요한 기능이 있으면 해당 폼들에 추가해. 

# 최종적으로 내 pc에 KepserverEx를 설치했는데 이것으로 확인할거임.
